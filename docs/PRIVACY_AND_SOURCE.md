# Privacy and Source

## What this repository is

A portfolio showcase for a production application. It describes the engineering of Would You Rather TV on Android TV; it is not a source distribution.

## What is published

- Written descriptions of architecture, design decisions and trade-offs
- An original diagram created for this showcase
- The app icon, resized
- One design asset from the app, labelled as artwork: the TV launcher banner

## What is intentionally not published

- Production source code, in whole or in part
- Question text and option text, and the question data files
- Build and signing configuration, certificates and keystores
- Firebase and Google service configuration, API keys and tokens
- Ad network identifiers and placement IDs
- Billing product IDs and prices
- User data of any kind
- Version control history of the production repository

## Images

- **There are no screenshots in this repository.** No captures of the app running on an Android TV or an emulator were available, and none have been mocked up or composed.
- **Everything shown is artwork.** The two images are the app icon and the TV launcher banner, and each is captioned as product artwork. The banner is the launcher image that the app declares for the TV home screen.
- **Nothing else exists to show.** The app draws its screens in code and ships no category illustrations, so there are no further image assets to publish.
- Images were re-encoded from raw pixels so no embedded metadata remains.
- **Diagram** is an original vector illustration.

## How the descriptions were produced

The production project was inspected read-only. Statements describe behaviour observed in code, manifests and build files. Where behaviour could not be confirmed it is worded conservatively or left out. No app was run to collect measurements.

## The store link

The Google Play link in the README was fetched and checked. The page title is "Would You Rather TV Party Game", and the identifier in the link is the application ID declared in the production build configuration.

## Publication checks

Before publishing, every file was checked for source code, credentials, signing material, personal data, email addresses, local file-system paths and embedded image metadata. None remain.

## Access

Source access for hiring or due-diligence purposes can be discussed at the owner's discretion.
